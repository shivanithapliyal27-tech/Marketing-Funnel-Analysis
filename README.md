# Marketing Funnel Analysis

## Project Overview
This project analyzes marketing-qualified leads and closed deals to understand lead source performance, conversion rates, and monthly trends. The dashboard was developed using SQL Server, Excel, and Power BI.

## Objectives
- Analyze total qualified leads and closed deals.
- Calculate the lead-to-deal ratio.
- Compare lead sources and their performance.
- Track monthly qualified leads and closed deals.
- Present key insights through an interactive Power BI dashboard.

## Tools Used
- **Microsoft SQL Server:** Data querying and analysis.
- **Microsoft Excel:** Data organization and KPI summaries.
- **Microsoft Power BI:** Dashboard creation and visualization.

## Dataset
The project uses the Olist Marketing Funnel dataset, including:
- `olist_marketing_qualified_leads_dataset.csv`
- `olist_closed_deals_dataset.csv`

## Key Performance Indicators
- Total Qualified Leads: 8,000
- Total Closed Deals: 842
- Closed Deals-to-Qualified Leads Ratio: 10.53%


- KPI cards for leads, closed deals, and conversion ratio.
- Qualified leads by lead source.
- Closed deals by lead source.
- Monthly qualified lead trends.
- Monthly closed deal trends.
- Qualified lead distribution by source.

## Project Files
- `Marketing_Funnel_Analysis_Dashboard.pbix` — Power BI dashboard.
- `Marketing_Funnel_Analysis_PowerBI_Ready.xlsx` — Excel workbook containing summary and analysis sheets.
- `Marketing_Funnel_Analysis_Project_Report.docx` — Project report.

## Conclusion
This project demonstrates how SQL Server, Excel, and Power BI can be combined to organize marketing data, evaluate lead-source performance, monitor monthly activity, and communicate business insights through a dashboard.
